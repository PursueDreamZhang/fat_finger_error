# 期货乌龙指日线初筛器 评分体系重构方案 (v3)

> 本方案基于 `output/full_20240101_20260610_v1/` 的真实结果 + 真实数据上的 P0 验证实验(见 §1.8)。是对 `2026-06-02-fat-finger-scoring-design.md` 的修订提案。A/C/E 三段式骨架保留。
>
> **v2 → v3 变更**：v2 押在"P0(窗口+min_periods)是唯一根因改动、C 饱和会随之自消"。**实验推翻了这个论断**（§1.8）：(1) P0 单独只把命中率从 6% 压到 4%，必须叠 k≈1.5 倍数才到 ~1%；(2) C 饱和是分桶结构问题，跟窗口无关，P0 下仍 98% 全 C=60。v3 因此把 k 倍数从"建议"升为 P0 必做项，把 P1.1（C 梯度化）从"可选门控"升为"附条件必要项"，并把 min_periods 立为一号旋钮（v2 把它当副效应标错了）。同时落实第二轮审查的 4 条必改 + 文字修订。

## 1. 诊断结论（已逐条复核 + 实验验证）

### 1.1 命中泛滥
valid 23,087（输出窗口内）；medium+high 999 → **4.33%** 判为中/高可信。真实乌龙指应为千里挑一，高 1~2 个数量级。

### 1.2 门槛过低 —— 真正病灶是 `min_periods=10`，不是"P99 太易碰"
- 实测当前 `range_pct>=range_q99` 命中率 **6.40%**、`normalized>=structure_q99` **6.95%**（理论 ~1%）。被拉高 6 倍的机械根因是：合约只要凑齐 10 个有效日就有 q99，而 P99 在 10~20 样本上估计偏低且抖 → 容易被超过。
- v2 把根因写成"P99≈近 20 日局部最大值"是表观描述；真病灶是 `min_periods=10` + 短历史让 P99 估计本身偏低。**因此 P0 的一号旋钮是提 min_periods，二号才是拉窗口，三号是 k 倍数。**

### 1.3 C 顶部饱和 —— 实验证明与窗口无关，是分桶结构问题
71/71 high 全 C=60（std=0）。实验（§1.8）确认：把窗口 20→60、min_periods 10→30 后，high 仍有 **98% C=60**。命中 P99 就一次性给满 40 的分桶设计不变，饱和永远在。**所以 P1.1（C 梯度化）无法靠 P0 替代** —— 但要不要修，取决于 P0+k 后 high 群体还剩多大（见 M2）。

### 1.4 弱对照样本
71 high 里 peer≥4 共 65、peer==3 共 1、peer==1 共 5。单 peer 的 median 是点估计不可靠，与 P0 正交。存在双弱样本（`JD2508 2025-08-01`）E=-10 仍 high=70。

### 1.5 A1/A2 共线
`A1>=8` 的行 75% 同时 `A2>=5`。A2 不是独立证据。**v1 的 wick 改法已撤（§6）**；A2 怎么改挂门控（需先有"共线导致实际误判"的证据）。

### 1.6 未处理的误报源
换月日 flag 算了没用；涨跌停无识别；close 分母污染（**当前无数据证据**，挂门控）。

### 1.7 calm 品种 **不是**命中泛滥的来源（v2 高估了）
实测 `structure_q99==0` 的 4740 条 calm 样本，medium+high 命中率仅 **0.27%**，远低于全体 4.49%。泛滥来自 `structure_q99>0` 的非 calm 样本。**所以 calm/fallback 不立专项**，P0 的 `k×q99` 倍数只在 `q99>0` 分支生效，`q99<=0` 仍走现有绝对 fallback（0.25/0.5/1.0）。M5 仅作监控，不作必改项。

### 1.8 P0 验证实验结果（v3 新增，决定 P0 参数）
在真实 22 品种、2024-01-01~2026-06-10 数据上，monkeypatch scoring 常数，分别跑 (window=20,min_periods=10) 与 (60,30)，量 ratio=`value/q99` 分布：

| 配置 | range ratio≥1.0 | ≥1.3 | ≥1.5 | struct ratio≥1.0 | ≥1.3 | ≥1.5 | high C=60 占比 |
|---|---|---|---|---|---|---|---|
| 基线 (20,10) | 6.40% | 2.34% | 1.30% | 6.95% | 3.63% | 2.59% | 97% |
| P0 (60,30) | 3.85% | 1.40% | **0.78%** | 4.42% | 2.30% | **1.63%** | 98% |

结论：
- **P0(60,30) 单独只把命中率从 ~6% 压到 ~4%，不够**；叠 **k=1.5** 后 A1≈0.8%、C1≈1.6%，进入目标 0.3%~1% 区间。→ **k 倍数是 P0 必做项，不是可选**。
- **C 饱和未破**（97%→98%），证实 §1.3：饱和是分桶问题。
- 附带发现：P0 单独（不加 k）跑出的 medium 数反升（5338→8198），说明光拉窗口对分数组合有非单调副作用（fallback/c_history_mask 交互）。→ **任何 P0 参数落地都必须用真实 before/after 验证，不能假设单调下降**。

## 2. 改动总览

| # | 改动 | 状态 | 依据 |
|---|---|---|---|
| **P0** | min_periods 10→30、window 20→60、**k=1.5 倍数（必做）**、buffer ≥100 自然日、保留 q99==0 的 fallback 分支、测试 fixture 迁移（**独立任务**） | **本轮必做** | §1.2、§1.8 |
| **P1.2** | C 上限随 peer 数衰减：peer==1→24、peer∈{2,3}→44、peer≥4→60 | **本轮必做（正交）** | §1.4 |
| **P2** | 换月日纳入 E 扣 5 | **本轮必做（正交）** | §1.6 |
| **P1.1** | C 顶部梯度化（双分支：q99>0 用倍数档，q99≤0 用绝对档） | **附条件必做** | §1.3、§1.8；触发见 M2 |
| P2' | 双弱样本重罚 | 门控 M4 | §1.4 |
| P3 | A 分母 pre_close guard；A2 形态化 | 撤 / 门控 | v1 公式错 |
| P4 | 涨跌停识别 | 门控 M6 | 需品种板幅 |

**等级阈值 30/50/65**：P0+k 后绝对分整体下移，这三条线**必须重新标定**。但标定服从命中率目标（M3 服从 M1，见 §4）。

## 3. 本轮必做的改动

### P0 —— 重新标定历史阈值（根因）

**为什么改**：§1.2 + §1.8。`min_periods=10` 让短历史合约拿到偏低抖动的 q99，命中率被拉到 6%；实验证明必须同时提 min_periods、拉窗口、加 k 倍数才能压到 ~1%。

**改法**（参数已由实验支撑，非拍脑袋）：
1. `ROLLING_MIN_PERIODS`：10 → **30**（一号旋钮，对应 §1.2 真病灶）。
2. `ROLLING_WINDOW`：20 → **60**（约一季度）。
3. **k 倍数（必做）**：触发从 `value >= threshold` 改为 `value >= 1.5 × threshold`。起始 k=1.5（实验显示 A1≈0.8%、C1≈1.6%，落在目标区间）。标定空间 1.3~1.7，由 §4 M1 微调。
4. **C 分支保留 fallback**：`structure_q99>0` 用 `1.5×q99`；`structure_q99<=0`（calm 品种，非泛滥源）仍走现有绝对 fallback（0.25/0.5/1.0）。A 分支 `range_q99` 无 0 值问题，直接 `1.5×range_q99`。
5. `TRADING_LOOKBACK_BUFFER_DAYS`：45 → **≥100 自然日**（实测滚动 60 交易日的自然日跨度 max=98、p95=95；取 100 才不赌运气）。更稳的做法是改为按交易日计数（≥60 交易日）。
6. **测试 fixture 迁移（独立任务，非 P0 子项）**：`tests/test_scoring.py` 的 test1/3/4/5 各 12 天、test6 13 天（`broad_wave_day`/`isolated_spike_day` 硬编码日期序号）、test7 32 天（`index<=11`/`index==32` 特判）。扩到 ≥35 个有效历史日时这些硬编码 index 和事件日期必须同步后移、断言语义保持。工作量被 v2 低估，单独立项。

**标定**：以 `full_20240101_20260610_v1` 为基线，落地后重跑，核 §4 M1（命中率 0.3%~1%）+ `AU2606 2026-05-20` 等已知尖刺仍 high。

> ponytail：不引入跨品种绝对阈值库；min_periods + window + k 三个旋钮，全部由 §1.8 实验数据支撑。

### P1.2 —— C 上限随 peer 数衰减（正交小修，v2 cap 表已修正）

**为什么改**：§1.4。单/少 peer 的 median 不稳，P0 不修这个。v2 的 cap 表让 peer==3 的 CS2409（A=20+C=52+E=0=72）仍 high，没压住。

**改法**（v3 修正）：规则统一为"**active_peer_count < 4 不可达 high**"：
```
C_cap = {1: 24, 2: 44, 3: 44, >=4: 60}[active_peer_count]
C_score = min(C1+C2, C_cap)
```
peer==1 → 最高 24（必 low）；peer∈{2,3} → 最高 44（A=20+C=44+E=0=64 < 65，必 medium 及以下）；peer≥4 → 不受限。5 条 peer==1 high + 1 条 peer==3 high 全部被压出 high。

### P2 —— 换月日纳入 E（正交小修）

**为什么改**：§1.6。换月日 active 集合跳变，C 基线最不稳；`main_reference_changed_today` 已在 `reference_selection.py:22` 算好并 merge 进 df，scoring 直接读列，零额外计算。

**改法**：`main_reference_changed_today==True` 时 E 扣 5（并入"取最重档"），`trigger_reasons` 打标"换月日基线不稳"。符合原设计 §7.3（在 E 里扣，不在 level 层补）。
> 落地前先统计换月日 vs 非换月日的 medium/high 命中率，确认换月日确实偏高再扣（避免无数据先立项）。

## 4. 决策门（P0 落地后实测，决定附条件项去留）

P0+P1.2+P2 落地后**重跑 full_run**，按下表测量。**M3 服从 M1**：等级线下调的幅度以不破坏 M1 的 0.3%~1% 命中率为上限（M1 是硬约束，M3 是软调参，冲突时让步）。

| 度量 | 目标 | 不达标时启用 |
|---|---|---|
| **M1** medium+high 命中率 | 0.3%~1%（硬约束） | >1.5% → k=1.7；<0.2% → k=1.3 |
| **M2** high 群体规模 + C 梯度 | high 数 < 30，或 C_score 在 `peer≥4 且 structure_q99>0` 子集上有梯度 | high 仍多且 C 仍饱和（子集 std≈0）→ 启用 P1.1（见下） |
| **M3** 已知尖刺（`AU2606 2026-05-20` 等，**须先列清单**）等级 | 仍 high | 降级 → 在不破坏 M1 前提下调等级线（如 30/50/65→28/47/62），每次下调后回看 M1 |
| **M4** 双弱样本是否达 high | 无 | 仍达 high → 启用 P2'：双弱 E 重罚至 -20 |
| **M5** calm 品种命中率 vs 全体（监控，非必改） | 不显著偏高 | 偏高才复核 fallback 绝对阈值 |
| **M6** 涨跌停样本（\|close-pre_settle\|/pre_settle 大）占 high 比例 | 低 | 偏高 → 启用 P4（需先备品种板幅数据） |

**M2 子集定义（修正 v2）**：饱和判定只在 `active_peer_count>=4 且 structure_q99>0` 的 high 子集上算 std，剥离 P1.2 cap 和 fallback 的干扰；同时报告 high 群体绝对规模，规模 < 30 时饱和可接受（screener 二元"极端/不极端"够用），不强制 P1.1。

**P1.1 触发时的双分支公式（替代 v2 错误的连续公式）**：
- `structure_q99>0` 分支：进入需 `normalized >= 1.5×q99`；之上分档 `1.5×→20`、`2.5×→30`、`4×→40`（C1）；C2 同理 `1.5×→10`、`2.5×→15`、`4×→20`。
- `structure_q99<=0`（fallback）分支：用绝对 normalized 档 `0.5→20`、`1.0→30`、`2.0→40`。
- 这样在"罕见区"内部有 3 档梯度，破饱和；q99 极小时走绝对档，避免 v1"ratio≥1 恒贴顶"的同型退化。

**P3 不立独立门控**：仅当 P0 后人工复核发现"已知未修复尖刺被明显低估"（量化：未修复尖刺的 A 分中位数比已修复尖刺低 ≥3 分）才做 A1 的 pre_close guard。

## 5. 验证方案

1. **回归**：以 `full_20240101_20260610_v1` 为 before，P0+P1.2+P2 落地后重跑同区间，产出 M1~M6 度量表。
2. **单元测试**：fixture 迁移（独立任务）后，新增：k 倍数生效（恰等于 1.5×q99 的样本改前过、改后不过）；C fallback 分支 `structure_q99==0` 仍按绝对阈值判；P1.2 peer<4 不达 high；P2 换月日 E 扣 5；P1.1（若触发）双分支梯度。
3. **文档同步**：P0 落地后修订 `2026-06-02-fat-finger-scoring-design.md` 的窗口、min_periods、k 倍数、buffer、peer 衰减、换月日条款；P1.1/门控项落地时再补。

## 6. 已撤回的改动及原因（供审核核对）

- **撤 C 连续公式 `C1=clip(40×normalized/q99,0,40)`**（v1）：ratio≥1 恒贴顶，零梯度。若 M2 触发，改用 §4 的双分支倍数/绝对档，不上线性连续公式。
- **撤 A2 换 wick_dominance**（v1）：对未修复尖刺反向打分（H=110 L=99 O=100 C=109 → wick=0.09），valid 里 285 条 high==low 除零。A2 暂不动。
- **撤等级封顶**（v1 P2.1）：与 §7.3 紧张且与 C-cap 重复。peer 数由 P1.2 C-cap 在分值层承担，双弱由 M4 决定。
- **撤 close→pre_close 全局换分母**（v1 P3）：推翻 §3.2.1。无数据证据前不全局改；仅挂门控。
- **撤"C 饱和随 P0 自消"论断**（v2）：§1.8 实验证伪，98% 仍饱和。P1.1 升为附条件必要项。
