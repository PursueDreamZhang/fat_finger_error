# 交接说明

这个目录是当前新版“期货乌龙指日线初筛器”的交接文档集合，建议接手人直接从这里开始阅读，不要先从旧版脚本入手。

2. [主设计稿.md](/Users/zhangchunfu/Nutstore%20Files/code/python/fat_finger_error/docs/new/主设计稿.md:1)

## 2. 每份文档分别负责什么

### [代码梳理文档.md](/Users/zhangchunfu/Nutstore%20Files/code/python/fat_finger_error/docs/new/代码梳理文档.md:1)

这份是**代码实现说明**，适合回答：

- 当前真实入口是什么
- 数据从哪里拉
- 缓存怎么命中和补数
- 样本状态怎么判
- A/C/E 怎么算
- HTML/CSV/JSON 是怎么生成的
- 具体经过了哪些文件和函数

如果接手人要快速理解“代码现在到底怎么跑”，先看这一份。

### [主设计稿.md](/Users/zhangchunfu/Nutstore%20Files/code/python/fat_finger_error/docs/new/主设计稿.md:1)

这份是**整体设计说明**，适合回答：

- 这套系统的目标是什么
- 输入输出是什么
- 数据流程大致怎么组织
- 样本状态有哪些
- HTML 报告应该展示什么

如果接手人想先理解“系统应该长什么样”，看这一份。

### [评分设计文档.md](/Users/zhangchunfu/Nutstore%20Files/code/python/fat_finger_error/docs/new/评分设计文档.md:1)

这份是**评分规则说明**，适合回答：

- 为什么只保留 `A/C/E`
- A/C/E 各自的业务含义是什么
- 活跃合约怎么定义
- 历史窗口怎么定义
- 等级阈值怎么划分

如果接手人要改评分逻辑，优先看这一份。

## 3. 遇到不同问题时先看哪份

- 想知道程序现在怎么跑：先看 `代码梳理文档`
- 想知道系统整体要做什么：先看 `主设计稿`
- 想知道某个分数为什么这样算：先看 `评分设计文档`
- 想改 HTML 展示或输出结构：先看 `主设计稿`，再看 `代码梳理文档`
- 想改评分口径：先看 `评分设计文档`，再改代码

## 4. 交接时需要特别说明的一点

当前新版主链路是：

- `run_daily_screen.py`
- `src/daily_screen/*`

不是旧版的：

- `fat_finger_detector.py`

如果接手人直接去看旧版脚本，容易把当前实现和历史实现混在一起。
